# Architecture definition for agents

> Outline. Target: version 0.5. Not ready to install.

- Specification-to-feature correspondence and ownership of behavior.
- Code homes, dependency direction, sibling isolation, and public interfaces.
- API/SPI, semantic intents, and application-owned navigation.
- Shared capabilities, permitted participation changes, and composition.
- Host-project conventions and available requirements, without assuming a local specification tree.
- Unclear boundaries and intent that require clarification.

The finished definition must be usable independently of the documentation tree and agent roster. Installation belongs in the [Setup guide](./setup-guide.md).
