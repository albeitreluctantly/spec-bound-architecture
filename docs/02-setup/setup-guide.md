# Setup guide

> Outline. Target: version 0.5.

- Establish the feature, shared-foundation, infrastructure, and application code homes.
- Define project conventions: stack, aliases, public entries, and local implementation choices.
- Configure ESLint to enforce public imports, sibling isolation, and dependency direction; check allowed and forbidden imports.
- Choose a specification home using [Workflows](../05-workflows/workflows.md#spec-driven-development).
- Optionally install the [standalone architecture definition](./architecture-definition.md) in the project's agent instructions.

See the [Overview](../01-overview/overview.md) for the codebase structure and the [Architecture guide](../03-engineering/architecture-guide.md) for dependency rules.
